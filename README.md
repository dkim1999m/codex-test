## Tienda de Calzado

Este repositorio contiene un prototipo sencillo de un ecommerce para la venta de calzado. 
Para visualizarlo solo es necesario abrir el archivo `index.html` en un navegador moderno.

El catálogo se genera dinámicamente con JavaScript y muestra algunas
animaciones y estilos personalizables para mejorar la experiencia de usuario.
